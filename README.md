# Quant Analytics

Независимая оценка риска инвестиционного портфеля для частных инвесторов: счета любых брокеров в одном отчёте, возможный убыток в рублях, стресс-тесты, оценка доходности и предложения по изменению состава портфеля («манёвры»), решение по которым принимает инвестор.

Академия Финтеха 2026, трек ВТБ «Финтех без границ», спринт 1. Копия кода для экспертной оценки на 31.10.2026.

## Как посмотреть

- Сайт: https://quantanalyticsclub.ru
- Учётная запись для экспертов указана в форме подачи. Режим учебный: виртуальный счёт, реальные заявки выключены.
- Котировки Московской биржи — с задержкой 15 минут (ISS).

Путь инвестора по слайду 5 презентации:

## Архитектура

- **backend/** — FastAPI, PostgreSQL с построчной изоляцией данных пользователей (RLS), Redis, Celery (подбор манёвров, загрузка данных, исполнение заявок).
- **frontend/** — Next.js 14, TypeScript.
- **Модели:** LightGBM (направление и «обгонит ли бумага рынок» на 20 торговых дней), сценарный прогноз, ARIMA и N-BEATS в ансамбле; ИИ-модель пишет текстовые пояснения к уже рассчитанным цифрам и сама цифр не создаёт.
- **Данные:** Московская биржа (ISS), брокеры по токену пользователя (Т-Банк, Финам), котировки США (Alpaca, Yahoo), Банк России.
- **Безопасность:** ключи брокеров хранятся зашифрованными, по умолчанию принимаются только права на чтение; реальные заявки — только после явного включения на платформе, с лимитами на размер и число заявок в день и подтверждением каждой заявки пользователем.
- **Правовой контур:** документы и согласия по 152-ФЗ и 149-ФЗ, журнал действий с персональными данными, удаление данных по запросу. Платформа не даёт индивидуальных инвестиционных рекомендаций.

Решения по архитектуре — `docs/adr/`, описание методик расчёта — `docs/methodology/`.

## Точность моделей

Направление цены на 1 день вперёд модель угадывает в 52,7% случаев против 50,4% у правила «всегда рост» (проверка на данных после 21.01.2026, 23 бумаги Мосбиржи и 12 бумаг США). Поэтому манёвры строятся на оценке риска и сценариях, а прогноз направления — одна из оценок, а не основа решения.

## Запуск локально

Нужен Docker. Для Windows есть сценарий, который собирает образы, применяет миграции и создаёт учётную запись:

```
powershell -ExecutionPolicy Bypass -File scripts\local-demo.ps1
```

Тесты бэкенда: `cd backend && python -m pytest -q app/tests`. Фронтенд: `cd frontend && npx tsc --noEmit -p . && npx vitest run`.
