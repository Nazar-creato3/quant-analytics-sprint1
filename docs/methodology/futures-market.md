# Рынок фьючерса (58B)

Профиль объёма: сумма количества сделок по уровню цены (шаг `tick`). POC — уровень с максимальным объёмом. Зона стоимости — расширение от POC до покрытия 70% объёма.

Кумулятивная дельта: покупки минус продажи по полю `side`/`direction`.

FUTOI — открытые позиции физлиц и юрлиц из фикстуры, сверенной с тремя датами. Живой ISS — отдельный коллектор.

Положительный фандинг платят длинные позиции коротким.
