# Наблюдаемость

Промпт 29. Латентность, ошибка, последнее известное значение, теневое расхождение и алерт записываются в процессе. Пустая выборка p95 — «нет данных». Метод p95 — nearest rank: ранг `ceil(0.95 * n)`.

Пороги из промпта: p95 API 500 мс, отчёт 180 с. Таймаут синхронизации и цель доступности не заданы (OQ-29-2).

При сбое внешнего сервиса чтение возвращает последнее значение с отметкой «последнее известное». Если значения не было, ответ «нет данных», исключение наружу не летит.

Трассы: OpenTelemetry SDK 1.45.1. Коллектор — опциональный контейнер профиля `monitoring`. Без endpoint — экспорт в память.

Откат: `FF_QA_OPS_OBSERVE=0`.
