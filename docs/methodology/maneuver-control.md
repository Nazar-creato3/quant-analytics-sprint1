# Контроль результата манёвра

Дата: 2026-10-07. Промпт 40.

## Доходность

На ряде цен, который уже есть у вызывающего кода. Первая точка — цена решения, последняя — конец горизонта. Стоимость = сумма (количество × цена) + деньги от сделок. Доходность = (конец − начало) / начало. Начало не равно нулю.

Бездействие держит исходные количества. Исполнение применяет заявки по их цене. Нет ряда, нет цены заявки или нулевое начало — «нет данных». Функция цены не скачивает.

Отклонённый манёвр: факт — бездействие, «если бы исполнили» — путь со сделками.

`expected_return` берётся из записи, если поле задано. Иначе ожидаемая доходность — «нет данных». Ошибка = фактическая доходность минус ожидаемая, только когда оба числа есть.

## Риск

Ожидаемый VaR — поле `impact.delta.var_95`, если генератор его уже записал. Фактический VaR — `risk_engine.compute_risk_for_holdings`. Нет ряда в риск-сервисе — «нет данных», не ноль.

## Качество типа

`config.json`: меньше `min_samples` ошибок — «нет данных». Средняя абсолютная ошибка не ниже `abs_error_off` — тип выключен и не попадает в генератор. Не ниже `abs_error_beta` — «бета», тип остаётся с пометкой. Иначе «готов».

Отказы и правки снижают оценку ранга не больше чем на `max_rank_penalty`. Доля одобрений оценку не повышает. Лимиты профиля эта функция не меняет.

Сводка без `user_id` и без свободного текста отказа.
