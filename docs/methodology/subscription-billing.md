# Подписка

Дата: 2026-10-07. Промпт 26.

Суммы читаются только из `config.json`. Пустое поле — «нет данных». Скидка партнёра применяется к сумме лишь когда `qa_partners` включён и сумма уже задана. Сейчас флаг партнёров выключен, сумма пустая.

Состояния: пробный и просроченный и отменённый дают чтение. Оплаченный даёт полный бумажный доступ. Live не открывается.

Повторное списание требует согласия и привязанной карты. Отмена — один вызов, она же снимает повторное списание. Отвязка карты блокирует следующее списание.

Событие фикстуры подписывается в тесте. Повтор того же номера не меняет состояние второй раз. Сумма фикстуры не записывается в конфиг цен.

Уведомление за сутки выключено. Текст лицензии тарифа пустой — «нет данных».

Откат: `FF_QA_SUBSCRIPTION=0`.
