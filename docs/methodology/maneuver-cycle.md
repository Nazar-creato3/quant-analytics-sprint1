# Цикл одобрения манёвра

Дата: 2026-10-07. Промпт 39.

## Состояния

Запись проходит только по разрешённым рёбрам:

предложен → просмотрен → отредактирован (версия увеличивается на 1) → одобрен, либо отклонён, либо истёк → отправлен → исполнен частично или полностью → закрыт.

Из «просмотрен» можно одобрить без правки. Повторная правка остаётся в «отредактирован». Отклонение и истечение срока доступны с предложенного, просмотренного и отредактированного. Иной переход запрещён.

## Правка

Пользователь меняет состав заявок или количество. Исходные заявки сохраняются. Разница — список полей, где значение изменилось. После правки влияние и pretrade считаются тем же `preview_orders`, что и проверка сделки. Вердикт `block` не даёт одобрить. Нет заявок — в влиянии «нет данных», одобрение такой правки не выполняется.

## Одобрение и отправка

Одобрение — отдельное действие с `confirm=true`. Перед статусом «отправлен» цена читается заново (`load_market_price`). Если рыночной цены нет, а в заявке источник `portfolio_book` или `user_book`, берётся цена заявки. Иной подстановки нет. Нет цены или нет `expires_at` — отправка не выполняется, причина «нет данных». Срок или сдвиг цены сверх порога из `maneuvers/config.json` переводит запись в «истёк» (`maneuver_expired`).

## Исполнение

Paper пишет сделку в книгу счёта `paper-act:{user}` с ключом `act:{id}:v{version}:f{n}`. Повтор того же ключа книга не дублирует. Объём меньше заявки — «исполнен частично»; добивка до заявки — «исполнен полностью». Объём больше заявки не записывается.

Live не создаёт заявку. Флаг `qa_act_live` выключен. При включённом флаге путь всё равно отказывает: нет LiveConfirm, нет проверки второго фактора из промпта 28 и нет машины состояний заявки (промпт 24).

## Журнал

Каждое событие: предыдущий хеш, профиль на момент записи, версии моделей, текст, который показан пользователю, полезная нагрузка. Хеш — SHA-256 от предыдущего хеша и канонического JSON без поля `hash`. Файл `events.jsonl` в каталоге `QA_MANEUVER_JOURNAL_DIR`. В pytest без этой переменной файл не пишется. PDF журнала по одному манёвру — черновик. Текст формы рекомендации советника в репозитории не утверждён (OQ-18-1).

## Откат

`FF_QA_MANEUVER_CYCLE=0` возвращает прежние переходы `decide` / `execute` (правка из «предложен», статус `executed_paper`). `qa_act_live` не включается этим откатом.
