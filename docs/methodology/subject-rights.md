# Права субъекта

Политика: `docs/privacy/subject-rights.md`.

Сканирование после удаления ищет почту, имя и токен во всех словарях этого модуля. Пустой список означает, что строка не осталась. Чужой профиль не затрагивается.

Срок ответа не берётся из памяти модели. Пока официальный текст не сверен, поле «нет данных».
