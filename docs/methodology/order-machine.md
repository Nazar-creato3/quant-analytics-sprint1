# Машина заявок

Дата: 2026-10-07. Промпт 24.

Состояния: создана, отправлена, принята, частично исполнена, исполнена, отклонена, отменена. Неразрешённый переход — ошибка. Повтор того же клиентского номера возвращает ту же заявку и не пишет вторую строку в книгу.

Бумажное исполнение пишет сделку в `portfolio_book` (счёт `paper-act`, площадка `act`). Внешний номер — ключ манёвра промпта 39, если он передан, иначе `client_order_id` и номер исполнения.

Live при выключенном `qa_act_live` отклоняется. Если флаг включить, заявка всё равно не уходит брокеру: сначала защитные лимиты из `config.json`, затем отказ адаптера. Финам: адаптера заявок в репозитории нет, статус «нет данных». Тинькофф из этой машины не вызывается.

Обеспечение, плечо, цена ликвидации и стоимость удержания берутся только из полей, которые передал вызывающий код. Иначе «нет данных». Формула ликвидации здесь не считается.

Автоматическая заявка по фьючерсу или вечному контракту без обеспечения отклоняется. Ручная заявка по инструменту вне справочника отклоняется, даже если пользователь подтвердил риск.

Ключ с правом вывода отклоняется прежней проверкой `inspect_key_permissions`.

Откат машины: `FF_QA_ORDER_MACHINE=0`. Криптовалюта Мосбиржи: `qa_moex_crypto` выключен, спецификаций нет.
