# Портфель против простой альтернативы (K1)

Цифры считает код (`benchmark_alt` + `returns` + `quant_math.book`). Языковая модель числа не пишет.

## Что сравнивается

За тот же период, с теми же пополнениями и выводами:

1. Портфель пользователя — TWR и MWR из сервиса доходности (Промпт 08).
2. Индекс гособлигаций полной доходности RGBITR (ISS, рынок index).
3. Фонд денежного рынка: тикер `LQDT` (константа `MONEY_MARKET_TICKER`).

Пополнение в дату t на сумму c покупает c / P_t паёв альтернативы. Вывод продаёт паи по P_t. Цена — последнее официальное закрытие на дату или раньше. Нет цены — «нет данных», ноль не подставляется. Вывод больше стоимости рукава — «нет данных».

## Метрики

- **TWR** альтернативы: связка подпериодов между потоками (GIPS), `time_weighted_return`.
- **MWR** альтернативы: XIRR actual/365 тех же потоков инвестора плюс конечная стоимость рукава, `money_weighted_return`.
- Разница стоимости — в рублях до копейки (`Decimal`, округление HALF_EVEN).
- Разница TWR/MWR — в процентных пунктах. Без оценки результата.

## Источник и дата

В ответе API и в интерфейсе: источник ряда и дата последней цены. Формулировка: результаты прошлых периодов не определяют будущие.
