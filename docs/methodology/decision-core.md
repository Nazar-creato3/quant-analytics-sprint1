# Главное сейчас

Слой не считает риск, доходность и налог заново. Он читает публичные функции модулей из матрицы связности и сортирует уже готовые цифры.

Уверенность — статус данных модуля: «по вашим данным» или «частично». Нет цифры — сигнал не показывается, в ответе строка «нет данных» по этому модулю.

Если портфель не менять, на экране остаётся та же цифра источника, пока модуль не пересчитает её на новых данных.

Журнал хранит показ, действие и через 1, 3 и 6 месяцев итог `decisions_report` (цена решений, методика `docs/methodology/decisions.md`). Веса типов сигналов в показанном порядке не меняются, пока основатель не примет ревью. Теневые веса не попадают в ранжирование.

Это не индивидуальная инвестиционная рекомендация. Решение принимаете вы.
