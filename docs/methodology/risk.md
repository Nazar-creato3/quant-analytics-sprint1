# Методика риска (Prompt 09)

## Основной VaR

Filtered historical simulation (FHS): доходности стандартизуются условной волатильностью EWMA (λ = 0.94, RiskMetrics 1996), остатки пересэмплируются и масштабируются на текущую σ. Версия конфига: `risk_engine.fhs.v1`.

Контрольные методы: простая историческая симуляция, параметрический (нормаль), Монте-Карло (фиксированный seed).

ES 97,5% — среднее потерь за порогом VaR (Acerbi / Tasche).

## Бэктест

- Купик (1995): безусловное покрытие.
- Кристофферсен (1998): независимость пробоев и условное покрытие.
- Длительности между пробоями (геометрическая H0).
- Светофор Базельского комитета: 99% VaR, 250 дней (0–4 зелёный, 5–9 жёлтый, ≥10 красный).
- Acerbi–Szekely (2014) Z1 с симуляционным p-value.

Отвержение Купика или Кристофферсена переводит статус в `beta` и публикует `risk.warning`.

## Аллокация

Компонентный и предельный VaR/ES по Эйлеру (Tasche; McNeil–Frey–Embrechts). Сумма компонент равна портфельному показателю (после нормировки численной производной).

## Вклад в риск (K4, R2)

Веса — доли NAV. Ковариация — дневные логдоходности, окно 252, сжатие Ледуа–Вольфа (`sklearn.covariance.LedoitWolf`). skfolio в K4 не используется.

- Волатильность: σ_p = sqrt(wᵀΣw); MRC_i = (Σw)_i / σ_p; RC_i = w_i · MRC_i; доля в риске PRC_i = RC_i / σ_p. Σ RC_i = σ_p.
- CVaR/ES на уровне α: L_p = −rw; хвост T = {L_p ≥ VaR_α}; RC_i^{ES} = w_i · mean_{s∈T}(−r_{s,i}). Σ RC_i^{ES} = ES_α.
- История короче 60 торговых дней помечается «короткая история». Нет ряда или цены — «нет данных», ноль не подставляется.
- «Что будет, если» пересчитывает те же формулы на гипотетической книге и не пишет портфель.

## Эффективное число ставок (R11)

ENB = exp(−Σ p_k ln p_k), где p_k — доли риска по главным компонентам Σ (Meucci 2009). Подписи компонент пользователю не показываются. Версия 2 и факторные доли — [factor-lens.md](factor-lens.md). skfolio 0.6.0 — зависимость продукта (65); K4 по-прежнему считает Ledoit–Wolf через sklearn.
