# Админка беты

Действие требует роль и второй фактор. Аналитик не получает список пользователей и не переключает флаги.

Поддержка и основатель видят идентификатор и статус. Токен в ответ не входит.

Переключение обычного флага требует одного подтверждения. Флаги live и помеченные для юриста не включаются: заключения нет.

Журнал не переписывается. Очереди, поставщики данных и квоты остаются «нет данных».
