# Версия алгоритма в журнале манёвра

Дата: 2026-10-07. Промпт 41.

Событие журнала (`maneuver_cycle.journal.seal_event`) включает `model_version` и `model_versions` в хеш. Подмена версии после подписи ломает проверку цепочки.

Файл `backend/app/services/accreditation/registry.json` хранит записи версий модулей, из которых собирается манёвр. Новая логика добавляет запись. Последняя запись должна совпадать с константами в коде (`versions_match`).

`replay_from_journal` читает заявки, текст и снимок профиля из события. Повторный расчёт не выполняется. Нет поля — «нет данных».

Режим реального счёта этим документом не включается.
