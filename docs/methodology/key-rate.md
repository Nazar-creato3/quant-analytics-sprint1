# Портфель и ключевая ставка (запрос 63)

Расчёт по вашим позициям и прошлым рядам. Не прогноз Банка России.

1. Облигации с фиксированным купоном: ΔP/P ≈ −D_mod·Δy + ½·C·Δy² (та же формула, что в 56). Параллельный сдвиг кривой по умолчанию.
2. Флоатеры: цена ≈ 0, доход за 12 месяцев = номинал × (ставка + спред).
3. Акции: доходность ≈ β_ставки × Δy. β из факторной линзы 65. Подпись: «по прошлой реакции рынка, не прогноз».
4. Деньги на счёте: процентный доход за 12 месяцев по новой ставке.
5. Исторические эпизоды — только даты из `data/cbr/meetings.yaml` с ссылкой на Банк России.

Интервал — бутстреп по акциям. Нет дюрации или беты — «частично» со списком.
