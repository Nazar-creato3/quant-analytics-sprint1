# Облигации

Источник формул: `docs/research/R5-bonds.md`, конвенции QuantLib Actual/365F.

- Грязная цена = чистая + НКД.
- YTM / YTP: ставка y, при которой PV потоков = грязная цена. День: `(date2-date1).days / 365`.
- Дюрация Маколея D = Σ t·PV(t) / P. Модифицированная D_mod = D / (1+y).
- Выпуклость C = Σ t(t+1)·CF / (1+y)^{t+2} / P.
- Стресс: ΔP ≈ −D_mod·Δy·P + ½·C·Δy²·P, Δy = ±1 и ±2 п.п.
- G-спред = y выпуска − y кривой ОФЗ (ISS `/iss/engines/stock/zcyc.json`) при той же дюрации.
- Флоатер: дюрация до ближайшего пересмотра; будущий купон — оценка (RUONIA/ключ + спред).
- ОФЗ-ИН: номинал индексируется по ИПЦ, отдельная пометка.
- Нет данных — поле «нет данных», ноль не подставляется.
- Кредитные рейтинги не показываются (L-13, вопрос юристу).
