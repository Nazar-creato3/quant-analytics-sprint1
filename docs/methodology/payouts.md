# Календарь выплат

- Источники: T-Invest `GetDividends`; ISS `/iss/securities/{secid}/dividends.json`.
- `GetBondEvents` нет в proto — купоны после слияния 56 из `bond_cashflow_events`.
- Последний день покупки: поле брокера или T+1 по календарю Мосбиржи («расчёт»).
- НДФЛ 13% до модуля K3. Иностранные бумаги — без числа, пометка «налог может отличаться» `[ЮРИСТ]`.
- `estimated`: дата по истории, размер не показывается.
- Гэп: факты за 5 лет, «по прошлым данным, не прогноз».
