# Цена решений (запрос 59)

Цифры считает код `decisions_report`. Языковая модель числа не пишет.

## Цена выбора времени

MWR и TWR берутся из `returns.compute_returns` (Промпт 08). Разница — в процентных пунктах годовых. В рублях: оценка `end × (MWR − TWR) / (1 + TWR)`. Один депозит без промежуточных потоков даёт разницу 0.

## Цена сделок

Ленивый двойник держит состав на первую сделку. Нет сделок сверх первой покупки — разница 0. Нет цен для пересчёта двойника — «нет данных».

## Диспозиция

FIFO по лотам. PGR = число реализованных прибылей / (реализованные + бумажные прибыли). PLR = число реализованных убытков / (реализованные + бумажные убытки). Бумажный результат — по открытым лотам и текущей цене из книги; без цены открытый лот не входит, статус «частично». Меньше 20 исходов или короче 12 месяцев — «мало данных для вывода».

## Продажи в просадку и покупки после роста

Продажа в просадку: IMOEX ниже максимума за 60 сессий более чем на 10%. Покупка после роста: бумага выросла более чем на 20% за 20 сессий до покупки. Нужны датированные закрытия; доходности без дат не подставляются под календарь. Нет ряда — «нет данных», ноль не пишется.

## Оборот

Продажи за период делятся на среднюю стоимость: (сумма депозитов + конечная стоимость) / 2. Конечная стоимость одна не используется.
