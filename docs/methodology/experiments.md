# Эксперименты

Назначение варианта устойчиво: один и тот же субъект получает один и тот же остаток хеша.

Размер выборки на группу:

`n = ceil((1.96 + 0.84)^2 * (p1*(1-p1) + p2*(1-p2)) / (p2-p1)^2)`

`p2 = p1 + эффект`. Если базовая доля или эффект пустые, результат «нет данных».

Победитель не называется, пока обе группы меньше порога, пока ошибки или нарушения лимита профиля выше потолка, или пока порог не задан. Сравнение долей идёт через произведение успехов на размер другой группы, без отдельной формулы точности прогноза.
