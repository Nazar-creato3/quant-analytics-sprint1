# Фьючерсы в риске и хедж (58A)

Реальная заявка из продукта не отправляется.

- Номинал позиции = количество × цена × стоимость пункта. В риск входит номинал, не ГО.
- Плечо = сумма |номиналов| / ликвидная стоимость счёта (`GetMarginAttributes` у брокера; без числа — «нет данных»).
- Запас до маржин-колла = (ликвидная − минимальная маржа) / |суммарный номинал|. Нет ГО или минимальной маржи — запас не считается.
- Хедж: N = β · V · доля / (цена фьючерса · стоимость пункта) для MIX/MXI/IMOEXF. Подпись: «расчёт для понимания, не рекомендация».
- Вечный: стоимость удержания — накопленный фандинг за 30 дней. Квартальный: базис и дни до экспирации.
