# Партнёрский переход

Дата: 2026-10-07. Промпт 25.

Флаг `qa_partners` выключен. Пока он выключен, онбординг отвечает как раньше: путь недоступен.

Включённый флаг хранит переход: щелчок при согласии, затем по одному шагу из отчёта брокера — счёт открыт, пополнение, активность. Пропуск шага — ошибка.

Скидка записывается на шаге «пополнение»: 15% и 2 месяца из решения Р5 и `config.json`. Передача в подписку (`subscription_handoff`) отдаёт эти числа и «нет данных» по самому списанию: промпт 26 не подключён.

Ожидаемое вознаграждение берётся из `reward_rate`. Поле пустое — «нет данных». Фактическое — из строки отчёта, если она передана.

Текст раскрытия берётся из `disclosure_text`, только если `contract_confirmed` истинно. Иначе «нет данных». Ссылка не содержит идентификатор пользователя. Выгрузка сверки тоже.

Откат: `FF_QA_PARTNERS=0`.
