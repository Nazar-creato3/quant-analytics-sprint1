# Бумажные боты

Промпт 27. Бумажная сделка проходит риск-проверку и пишется в книгу (`record_bot_trade`, счёт `paper-bots:{user}`). Защита сравнивает переданную отметку со стопом. Live отклоняется, пока `qa_act_live` выключен.

Комиссия, проскальзывание и маржа бессрочного контракта в конфиге пустые. Подставлять 0.5 вместо спреда в прогоне Composer нельзя: без спреда оценка микроструктуры остаётся нулём поля по умолчанию и в методике записана как отсутствующая.

Число испытанных вариантов считается вместе с вероятностью переобучения (CSCV) и deflated Sharpe (Bailey, López de Prado, 2014). Короткая выборка возвращает «нет данных».

Старые grid, DCA и momentum не удалены 2026-10-07: их состояние по-прежнему в Redis. Новый вход бумаги — `bot_core`.

Откат: `FF_QA_BOT_CORE=0`.
