# Поддержка

Обращение принимает страницу, версию, идентификатор запроса, коды ошибок и описание. Строка с `@`, `token`, `password`, `secret` или `email` не сохраняется.

Снимок не пишется: текст согласия пустой. Даже при согласии в запросе в хранилище остаётся «нет данных».

Slack и почта не вызываются. Частые страницы считаются по уже принятым обращениям. Пустой список — «нет данных».
