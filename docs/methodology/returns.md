# Методика доходности (Prompt 08)

- **TWR:** геометрическая связка подпериодов. На дату внешнего потока (пополнение/вывод) портфель переоценивается по official_close. Поток не входит в доходность подпериода (GIPS).
- **MWR:** XIRR actual/365: Ньютон, затем бисекция (`quant_math.book.money_weighted_return`).
- **Modified Dietz:** только резерв; в API `dietz_used=false`, пока не включён явно.
- **Net / gross:** две цифры — до и после комиссий и налогов.
- **Аннуализация:** только если длина окна > 365 дней.
- **Ориентиры:** RUB — MCFTR (+ RGBITR для облигаций); US — пометка прокси, если нет лицензии S&P TR; крипта — BTC-USD.
- **K1 простая альтернатива:** те же потоки в RGBITR и LQDT — [k1-simple-alternative.md](k1-simple-alternative.md).
- **Неполная история:** расчёт на доступном участке + `incomplete` + предложение загрузить отчёт.
