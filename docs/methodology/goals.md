# Цели с вероятностью (K5)

Симуляция путей до даты цели: дневные доходности берутся с возвращением из истории портфеля (bootstrap, не нормальное распределение). Seed фиксирован и пишется в ответ.

Интервал MAPIE 0.9.0 (`method=plus`) строится по однодневным доходностям и масштабируется на горизонт. Если MAPIE не сходится — поле `mapie` пустое, bootstrap остаётся.

Подпись в интерфейсе: расчёт по прошлым данным, не обещание результата.
