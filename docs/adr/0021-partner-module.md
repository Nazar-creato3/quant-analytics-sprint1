# ADR 0021 — Партнёрский модуль выключен до договора

Статус: принято 2026-10-07 (промпт 25).

## Контекст

Промпт 25 просит партнёров, статусы, сверку и скидку Р5. Формулировка раскрытия и ставка вознаграждения зависят от договора. Договора в репозитории нет.

## Решение

1. Флаг `qa_partners` выключен. Рекламная маркировка — отдельный флаг `qa_partner_ads`, тоже выключен.
2. Скидка 15% на 2 месяца — параметры Р5, не тариф брокера. Она пишется только после статуса «пополнение» из отчёта брокера.
3. Пустые поля договора остаются «нет данных». Ссылка и выгрузка сверки не содержат идентификатор пользователя.
4. Подписка промпта 26 не строится. `subscription_handoff` только передаёт уже посчитанную скидку.

Откат: `FF_QA_PARTNERS=0`. Новых зависимостей нет.
