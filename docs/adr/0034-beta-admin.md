# ADR 0034 — Админка беты без включения live

Статус: принято 2026-10-07 (промпт 53).

## Контекст

Промпт 53 просит роли, второй фактор, приглашения, журнал и переключение флагов. Письменного заключения по флагам live и `[ЮРИСТ]` нет (OQ-00-5). Секрет второго фактора и лимит мест не заданы.

## Решение

1. Роли: основатель, поддержка, аналитик. Аналитик читает только сводку метрик.
2. Без подтверждённого второго фактора действие отклоняется. Секрет на экран не выводится.
3. Приглашение не создаётся, пока лимит мест пустой.
4. Флаги live, партнёров, рекламы, предзаказа и уведомления подписки этим разделом не включаются, даже после двух подтверждений основателя.
5. Журнал действий только дополняется. В нём хеш действующего лица, без адреса.
6. Очереди, поставщики и квоты — «нет данных». Здоровье сервисов читается из промпта 29.

Откат: `FF_QA_BETA_ADMIN=0`. Новых зависимостей нет.
