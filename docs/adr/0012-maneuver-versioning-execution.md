# ADR 0012 — Версия алгоритма манёвра и связь с исполнением (Промпт 34)

Статус: принято 2026-10-06 (документы; код исполнения — 24/39).

Решение:

1. У сохранённого манёвра обязательны `model_version` (код генератора) и `inputs_hash` (профиль, правила, снимок книги, идентификаторы рядов 04, `forecast_log` 11A, метка режима 12). Без hash — не исполнять.
2. Исполнение принимает **одобренный** `ManeuverRecord`, не сырой сигнал пайплайна. Paper — книга 05, счёт копии. Live — только `qa_act_live` и тот же pretrade 10, что ручная заявка.
3. Влияние на риск до одобрения — единственный расчёт «проверки сделки» (`preview_trade` после исправления D2 в 37/10): FHS 09, HHI 14, стресс 13, гейт 10. Запрещено считать VaR в `risk.engine.RiskEngine` для этого шага.

Обоснование: D-18-1 (журнал, paper, lawyer live); один источник истины по риску (E46-08).
