# ADR 0030 — Своя таблица событий, без отдельного сборщика

Статус: принято 2026-10-07 (промпт 50).

## Контекст

Промпт 50 просит хранилище событий и сравнение своей таблицы в PostgreSQL/TimescaleDB с самостоятельно размещаемой системой аналитики. Промпт 02 ограничивает хост 8 ГБ. Этот лимит здесь не перемерен. Пакетов PostHog, Plausible и OpenTelemetry в зависимостях нет.

## Решение

1. События остаются в этом процессе и по форме совпадают с таблицей `product_events`.
2. Отдельный сборщик не ставится: он занял бы память сверх непримеренного бюджета.
3. Данные третьим сторонам не отправляются.
4. В строке хранится хеш идентификатора. Почта, имя, телефон и токен в свойства не принимаются.
5. Пока текст согласия пустой, строка не пишется. Режим «не отслеживать» тоже не пишет строку.
6. Миграция и гипертаблица в этом шаге не создаются (OQ-50-2).

Откат: `FF_QA_PRODUCT_ANALYTICS=0`. Новых зависимостей нет.
