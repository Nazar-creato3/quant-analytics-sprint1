# ADR 0011 — Хранение манёвров и журнала (Промпт 34)

Статус: принято 2026-10-06 (документы; реализация — Промпт 39).

Решение: каноническая запись манёвра и неизменяемый журнал живут в PostgreSQL (append-only журнал с hash-chain как у `act_desk._append_journal`). In-memory `_maneuvers` / `_journal` в `act_desk.service` — временный носитель до 39, с датой удаления в отчёте 39.

Не решение: таблица `Maneuver` пайплайна остаётся операторским наследием до перевода генератора (37); не считать её SoT для шага «действовать».

Обоснование: RAM не переживает рестарт и не проходит стирание/аудит так же, как книга 05; два хранилища дают два «одобрено».
