# ADR 0009 — Реестр инструментов AI Chat и MCP

Статус: принято временно 2026-10-05 (Промпт 22). Откат: оставить in-process `qa_registry`.

Решение: инструменты ядра живут в типизированном реестре процесса (`app.services.chat.qa_registry`). Заявки запрещены. Вынос в отдельный MCP-сервер платформы откладывается: сейчас один процесс, один журнал, меньше поверхности. MCP — за флагом после Промпта 27, если понадобится единообразие для внешних агентов.
