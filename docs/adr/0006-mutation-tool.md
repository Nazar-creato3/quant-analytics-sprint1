# ADR 0006 — мутационное тестирование ядра

Сравнение 2026-10-04:

| инструмент | плюс | минус на этом репо |
|---|---|---|
| mutmut | зрелый | отдельный процесс на мутанта; плохо стыкуется с PYTHONPATH `backend` |
| cosmic-ray | распределённые воркеры | тяжёлый setup для CI 01B |
| `scripts/mutation_core.py` | фиксированный набор операторов, порог 80%, отчёт JSON | не полный AST |

Решение: in-repo скрипт для CI/ночи; mutmut не блокирует. Порог: `docs/qa/mutation/threshold.json`.
