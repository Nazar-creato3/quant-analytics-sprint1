# ADR 0018 — Контроль результата манёвра

Статус: принято 2026-10-07 (промпт 40).

## Контекст

Промпт 38 передал файл `docs/models/maneuver-history-control.json`. Промпт 39 хранит решение пользователя. Промпт 40 сравнивает факт с ожиданием и с бездействием и может выключить тип.

## Решение

1. Атрибуция живёт в `maneuver_control`. Ряд цен передаёт вызывающий код. Нет ряда — «нет данных».
2. Фактический VaR читается из `risk_engine.compute_risk_for_holdings`, не из отдельной формулы.
3. Правило беты и отключения — пороги в `config.json`, по средней абсолютной ошибке ожидаемой доходности. Мало наблюдений — «нет данных», тип не выключается.
4. Ранг может только снизиться. Доля одобрений и лимиты профиля в эту формулу не входят.
5. Личный блок пишется в `portfolio_report.assemble` и в `GET /act/control`. Сводка `GET /act/control/stats` без идентификатора пользователя.
6. Файл истории промпта 38 читается через `read_control_input` и в личные доходности не подмешивается.

Откат: `FF_QA_MANEUVER_CONTROL=0`. Новых библиотек нет.
