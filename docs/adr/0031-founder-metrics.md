# ADR 0031 — Главная метрика: активация за 24 часа

Статус: принято 2026-10-07 (промпт 51).

## Контекст

Промпт 51 просит выбрать главную метрику и считать активацию, удержание, воронку манёвров, долю анкет и время до первого отчёта. Целевое число основатель не задал.

## Решение

1. Главная метрика — активация: успешное подключение счёта и показ первого отчёта в течение 24 часов.
2. Формула одна: запросы в `metrics.sql`. Представления PostgreSQL в файле названы и в базу не ставились.
3. Пустой набор не заменяется нулём.
4. Цель метрики — «нет данных».
5. Сводка для Slack строится из тех же строк. Вебхук пустой, отправки нет.

Откат: `FF_QA_FOUNDER_METRICS=0`. Новых зависимостей нет.
