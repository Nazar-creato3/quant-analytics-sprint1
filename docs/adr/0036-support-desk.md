# ADR 0036 — Обращения без почты и без Slack

Статус: принято 2026-10-07 (промпт 55).

## Контекст

Промпт 55 просит сообщение о проблеме, контекст без персональных данных, снимок только с согласия, запись, Slack и ответ по почте. Вебхук, транспорт почты и текст согласия на снимок пустые. Список известных проблем не задан.

## Решение

1. Обращение хранится в памяти процесса. Почта и токен отклоняются.
2. Снимок не сохраняется.
3. Уведомление Slack не отправляется. Ответ по почте — «нет данных».
4. Страница состояния показывает «нет данных», пока список проблем пуст.
5. Сводка частых страниц строится из принятых обращений и не содержит текст описания.

Откат: `FF_QA_SUPPORT=0` и удаление `/support` из публичных путей. Новых зависимостей нет.
