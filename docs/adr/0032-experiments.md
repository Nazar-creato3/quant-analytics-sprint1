# ADR 0032 — Фиксированный горизонт, эксперимент выключен

Статус: принято 2026-10-07 (промпт 52).

## Контекст

Промпт 52 просит устойчивое назначение, размер выборки и правило, при котором малая выборка не называет победителя. Последовательные границы основатель не задал. Имени эксперимента, базовой доли и эффекта в конфиге нет.

## Решение

1. Назначение — остаток хеша от имени эксперимента и субъекта. Повторный вызов возвращает тот же вариант.
2. Горизонт фиксированный: сравнение только после набора `n` в каждой группе. Последовательный тест не используется.
3. Размер группы считается нормальным приближением с квантилями 1.96 и 0.84, когда переданы базовая доля и эффект. Без них ответ «нет данных». Эти квантили — константы формулы, не цель продукта.
4. Ошибки и нарушения лимита профиля блокируют победителя, если они выше потолка. Потолок без решения — «нет данных».
5. Без записи решения основателя эксперимент не стартует. Флаг по умолчанию выключен.

Откат: `FF_QA_EXPERIMENTS=0`. Новых зависимостей нет.
