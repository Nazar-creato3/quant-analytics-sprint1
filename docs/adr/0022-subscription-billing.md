# ADR 0022 — Подписка без утверждённой цены

Статус: принято 2026-10-07 (промпт 26).

## Контекст

Промпт 26 просит оплату, права и страницу подписки. Цена не утверждена. Боевой магазин ЮKassa уже умеет создавать счёт из `SUBSCRIPTION_AMOUNT_RUB`. Этот шаг не объявляет то значение тарифом.

## Решение

1. Новый контур читает цены из своего конфига. Пустые суммы не заменяются числом.
2. Доступ пробный / оплачен / отменён считается здесь и не включает live. Прежняя AccessPolicy не переписывается.
3. Оплата в тесте — фикстура с подписью и идемпотентным номером. Сеть ЮKassa не вызывается.
4. Скидка партнёра запрашивается у `subscription_handoff`. Пока `qa_partners` выключен, скидка не подставляется.
5. Уведомление за сутки — флаг `qa_subscription_notice`, выключен.

Откат: `FF_QA_SUBSCRIPTION=0`. Новых зависимостей нет.
