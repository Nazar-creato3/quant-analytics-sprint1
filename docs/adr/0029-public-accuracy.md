# ADR 0029 — Публичная точность только из журнала

Статус: принято 2026-10-07 (промпт 49).

## Контекст

Промпт 49 просит страницу точности из журнала 11A: горизонты, интервалы, наивная модель, слабые периоды и хеш. Журнал уже считает сводку и помечает её `public: False`. Отдельного листа формул стресса и концентрации в `docs/methodology` нет.

## Решение

1. Публичный ответ копирует поля `internal_summary`. Второй формулы нет.
2. Пустой журнал не показывает 0 и не показывает 0.5.
3. Хеш пересчитывается из `row_hash`. Чтение не пишет дневной снимок.
4. Разрез по инструменту и слабые периоды остаются «нет данных», потому что сводка их не содержит.
5. Публичная методика ссылается на уже написанные документы и не копирует формулы.

Откат: `FF_QA_PUBLIC_ACCURACY=0`. Новых зависимостей нет.
