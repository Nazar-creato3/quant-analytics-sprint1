# ADR 0007 — резервные копии

WAL PITR и внешний S3: провайдер и цена не согласованы (D-02-1).

Решение сейчас: интерфейс локальной цели `.data/backups/` + `scripts/backup_verify.py` (dump tar.gz, restore, сверка COUNT). Ежедневный S3 и шифрование ключом основателя — после выбора провайдера. Не считать копию сделанной без проверки восстановления.
