# ADR 0019 — Реестр версий для пакета аккредитации

Статус: принято 2026-10-07 (промпт 41).

## Контекст

Промпт 41 просит неизменную версию алгоритма в журнале, новую запись при смене логики и воспроизведение рекомендации по журналу. Реальный режим остаётся выключенным. Тексты указаний в репозиторий не копируются.

## Решение

1. Журнал манёвра уже подписывает `model_version` и `model_versions`. Отдельный журнал не заводится.
2. `accreditation/registry.json` — журнал смен версий. Сверка с константами модулей — `versions_match`. Расхождение роняет тест.
3. `replay_from_journal` показывает записанное событие и не пересчитывает цены.
4. Флаг `qa_act_live` не включается. Новых зависимостей нет.

Откат: удалить вызов сверки из тестов и пакет `accreditation`. Журнал манёвра промпта 39 при этом остаётся.
