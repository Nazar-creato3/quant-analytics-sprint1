# ADR 0001 — Менеджер пакетов Python: uv

Статус: **принято** (D-00A-1, 2026-10-03). uv + lock — шаг 2 в 01A после Next 16.3.8.

## Контекст

Зависимости заданы `requirements.txt` без единого lock. Протокол качества требует `uv.lock`.

## Варианты

1. Остаться на pip + requirements (как сейчас).
2. Ввести uv, сгенерировать lock от текущего pin, CI ставит из lock.
3. Poetry / PDM.

## Решение (временное до утверждения)

Вариант 2: uv в 01A шагом 1, без смены версий пакетов.

## Последствия

- Воспроизводимые сборки.
- Нужно обновить README и CI.
- Откат: вернуться к `pip install -r requirements.txt`.
