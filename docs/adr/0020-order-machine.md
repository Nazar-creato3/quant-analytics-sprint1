# ADR 0020 — Машина заявок без отправки live

Статус: принято 2026-10-07 (промпт 24).

## Контекст

Промпт 24 требует состояния заявки, идемпотентность, сверку, аварийную остановку и лимиты live. Адаптера заявок Финам в репозитории нет. Запрос ISS Мосбиржи по вечным фьючерсам в этом шаге не ответил (504). Спецификации контрактов не выдумываются.

## Решение

1. Состояния и журнал переходов живут в `order_machine`. Бумажная сделка пишется в ту же книгу, что и манёвр промпта 39.
2. Live не отправляется. `qa_act_live` остаётся выключенным. Включённый флаг всё равно не вызывает брокера.
3. Обеспечение и ликвидация — только переданные поля, иначе «нет данных».
4. Расхождение со снимком брокера или отсутствие снимка блокирует автоматические заявки этого пользователя. `halt` отменяет активные автоматические заявки и останавливает `auto_execute_paper_maneuvers`.
5. Защитные лимиты — числа в `config.json`, не тариф брокера. Снятие лимита — только с `confirm` и записью.

Откат: `FF_QA_ORDER_MACHINE=0`. Новых зависимостей нет.
