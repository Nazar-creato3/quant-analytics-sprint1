# ADR 0023 — Бумажный бот без внешнего движка

Статус: принято 2026-10-07 (промпт 27).

## Контекст

Промпт 27 просит один сервис ботов, книгу, риск-проверку и честный бэктест. В репозитории уже есть три движка и Redis. Внешний движок (Freqtrade и аналоги) не подключается, пока бумажный путь не является единственным.

## Решение

1. Бумажное открытие идёт через `bot_core`: риск-проверка, запись в книгу, событие.
2. Live не включается. Дней бумаги в конфиге 30, но флаг `qa_act_live` остаётся выключенным.
3. Комиссия и проскальзывание не выдумываются.
4. Оценка микроструктуры 0.5 из дневного прогона Composer снята.
5. Freqtrade не реализуется. Заметка: `docs/research/external-bot-engines.md`.

Откат: `FF_QA_BOT_CORE=0`. Новых зависимостей нет.
