# ADR 0005 — Инфраструктура связности (Промпт 01)

Статус: принято 2026-10-03.

Решение: сканеры на AST/тексте без import-linter; нарушения ядра копятся в JSON и падают только если появились новые; Testcontainers и живые песочницы — opt-in (`QA_TESTCONTAINERS=1`); e2e-сценарии xfail до фаз продукта; pip-audit/npm audit в CI как advisory (OQ-00A-1), пока не закрыты известные CVE стека.
