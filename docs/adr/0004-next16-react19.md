# ADR 0004 — Next.js 16.3.8 и React 19

Статус: **принято, первый PR 01A** (D-00A-1): Next.js 16.3.8 сразу, можно до слияния 01.

Реализовано в PR 01A-next: Next **16.3.8**, React **19.2.0**. Security: https://nextjs.org/blog/september-2026-security-release — патч 16.3.8 (Active LTS). `next build` на этой ветке: 49 маршрутов, exit 0. Middleware ещё на старом соглашении (предупреждение, не блокер).

Решение: 16.3.8 + React 19 отдельным PR (первый шаг 01A). Альтернатива 15.5.27 не понадобилась: сборка прошла.

React Compiler 1.0: оценить, не включать в CI обязательно (как ty).
