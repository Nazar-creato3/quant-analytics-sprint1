# ADR 0028 — Лист ожидания без капчи и без платежа

Статус: принято 2026-10-07 (промпт 48).

## Контекст

Промпт 48 просит двойное подтверждение, согласие [ЮРИСТ], хранение по промпту 28 и предзаказ. Текст согласия не опубликован. Промпт 28 не начат. Цена подписки пустая. Провайдер не выбран.

## Решение

1. Открытая форма не сохраняет адрес, пока согласие «нет данных».
2. Фикстура проверяет подтверждение и отписку одним вызовом. Почта и Slack не вызываются. Текст уведомления не содержит адрес.
3. Спам: скрытое поле и предел 5 записей фикстуры. Сторонняя капча не подключается.
4. Предзаказ выключен. Пустая цена не создаёт платёж, даже если флаг включить в тесте.
5. Сравнение комиссий, ИП, фискализации и возвратов — D-48-1, все «нет данных».

Откат: `FF_QA_WAITLIST=0` и `FF_QA_PREORDER=0`. Новых зависимостей нет.
