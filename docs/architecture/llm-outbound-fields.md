# Поля, которые уходят к модели (A1)

Дата: 2026-10-06. Код: `prepare_llm_outbound` в `backend/app/services/privacy/service.py`.

Вызов идёт через `LLMService` (пояснения при флаге, текст прогноза, чат) и через OpenAI-совместимый клиент терминала (в том числе формулировки манёвров в debate). Сырые значения из таблицы вырезаются до HTTP.

| Поле | Что делается | Можно отправить |
|---|---|---|
| `account_id`, `broker_account_id`, `account_number`, `broker_account` | замена на префикс sha256 (16 hex) | только хеш |
| `name`, `client_name`, `full_name`, `first_name`, `last_name`, `holder_name`, `user_name` | удаление, если значение похоже на имя (пробел или кириллица) | нет |
| `broker_token`, `token`, `api_token`, `tinkoff_token`, `access_token`, `authorization` | удаление | нет |
| email и присваивания `api_key` / `api_secret` / `password` | удаление | нет |
| тикер, цена, количество, процент, метка режима, текст шаблона после вырезания | остаётся | да |
| имя функции-инструмента из одного идентификатора | остаётся | да |

Та же строка в свободном тексте вырезается, если она уже была в чувствительном поле или подписана (`account_id=`, `name: Имя Фамилия`, `token=`). Имя без поля и без такой подписи не распознаётся (OQ-A1-3).

Поставщик модели этим файлом не назначается. См. OQ-A1-1.
