# tax_ru (K3)

Налоговые оценки по правилам РФ. Флаг `qa_k3_tax` (`[ЮРИСТ]`). Только `mode=paper` / демо, пока методику не подтвердит юрист.

## Что считает

- ЛДВ: дата льготы, налог при продаже сегодня и после даты.
- НДФЛ года: 13% до 2,4 млн ₽, 15% сверх (цифры OQ-36-1).
- Фиксация бумажного убытка до 31 декабря: на сколько уменьшится налог.
- ИИС: тип и ограничения, если брокер их отдал (после 31.12.2023 — OQ-36-3).

Числа — из `target_portfolio.tax` (один источник). Тексты UI — `legal/ui_texts.ru.yaml`.

## Откат

`FF_QA_K3_TAX=0`. Потребители (купоны облигаций) снова показывают 13% с пометкой.
