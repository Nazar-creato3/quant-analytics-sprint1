# Цикл одобрения манёвра (промпт 39)

Владелец записи — `act_desk`. Этот пакет задаёт переходы, повторную проверку перед отправкой и PDF журнала.

Состояния: предложен → просмотрен → отредактирован (версия N) → одобрен / отклонён / истёк → отправлен → исполнен частично или полностью → закрыт. Иной переход — `TransitionError`.

Правка заново вызывает `act_desk.preview_orders` (влияние и pretrade). Одобрение требует `confirm=true`. Перед отправкой цена читается заново. Нет цены или нет срока — «нет данных», заявка не уходит. Сдвиг цены или конец срока переводит запись в «истёк».

Paper пишет сделку в книгу 05 с ключом `act:{id}:v{version}`. Live не исполняется: `qa_act_live` выключен. Даже при включённом флаге заявка не создаётся, пока нет машины состояний промпта 24, LiveConfirm и проверки двухфакторной аутентификации.

Журнал — хеш-цепочка. Каталог файла: `QA_MANEUVER_JOURNAL_DIR`. В pytest без этой переменной цепочка остаётся в памяти процесса. Откат цикла: `FF_QA_MANEUVER_CYCLE=0` (прежние переходы `decide` / `execute`).
