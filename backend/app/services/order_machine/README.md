# Машина заявок

Промпт 24. Live не отправляется: `qa_act_live` остаётся выключенным.

`submit_order` ведёт заявку по состояниям и пишет бумажное исполнение в книгу `portfolio_book` с внешним номером. Повтор того же `client_order_id` не создаёт вторую сделку. `halt` отменяет активные автоматические заявки. `venue_order_adapter` для Финам возвращает «нет данных»: адаптера заявок в репозитории нет.

Откат: `FF_QA_ORDER_MACHINE=0`. Криптовалюта Мосбиржи: `qa_moex_crypto` выключен.
