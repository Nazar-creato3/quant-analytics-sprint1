# Подписка

Промпт 26. Суммы в `config.json` пустые: цена «нет данных», живой счёт ЮKassa эта служба не создаёт. Уведомление за сутки до списания выключено (`qa_subscription_notice`).

Повтор события с тем же номером не меняет статус второй раз. Отмена — один вызов. Отвязка карты останавливает повторное списание. Скидка партнёра читается из `subscription_handoff` и не включается, пока `qa_partners` выключен.

Откат: `FF_QA_SUBSCRIPTION=0`.
