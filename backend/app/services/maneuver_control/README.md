# Контроль результата манёвра (промпт 40)

Считает фактическую доходность на заданном ряде цен, доходность бездействия и ошибку против поля `expected_return`, если оно есть. Ряд цен функция не скачивает и не выдумывает: нет ряда — «нет данных».

Риск «после» берётся из `risk_engine.compute_risk_for_holdings`. Нет ряда в риск-сервисе — `actual_var_95` = «нет данных».

Правило качества по типу (как перевод в бету в 11B): при числе ошибок меньше `min_samples` статус «нет данных». Иначе средняя абсолютная ошибка сравнивается с `abs_error_beta` и `abs_error_off` в `config.json`. Статус `off` убирает тип из генератора.

Оценка ранга может только снизиться из-за отказов и правок. Доля одобрений в формулу не входит. Лимиты профиля эта функция не меняет.

Откат: `FF_QA_MANEUVER_CONTROL=0`.
