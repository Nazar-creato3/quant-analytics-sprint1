# Аккредитация программы

Промпт 41. Реальный режим не включается. `qa_act_live` остаётся выключенным.

`code_versions` читает версии модулей манёвра. `versions_match` сверяет их с последней записью `registry.json`. Новая логика — новая запись, старая не правится. `replay_from_journal` возвращает заявки и текст из уже подписанного события журнала и ничего не пересчитывает.

Документы: `docs/legal/accreditation/`.
