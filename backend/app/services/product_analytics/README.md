# product_analytics

События продукта пишутся в память процесса. Текст согласия в `config.json` пустой, поэтому без фикстуры запись не сохраняется. Идентификатор хранится только как хеш. Почта, имя и токен в свойства не принимаются.

Откат: `FF_QA_PRODUCT_ANALYTICS=0`.

Таблица `product_events` описана в `table_ddl()`. Миграция в этом шаге не применялась.
