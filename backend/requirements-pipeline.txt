# ─────────────────────────────────────────────────────────────────────────────
# Celery worker + full pipeline / ML / news stack.
#
# WHY THIS FILE EXISTS
#   The Celery worker imports every module in celery_app.include (pipeline,
#   execution, backtest, data_ingestion). The pipeline pulls numpy/pandas/
#   scikit-learn/lightgbm. These packages have prebuilt Windows wheels for
#   CPython 3.11 but do NOT reliably build/install on Python 3.14 — which is
#   why a global-3.14 Celery worker crashed on `import numpy` and consumed no
#   tasks at all (news + maneuvers both dead).
#
# INSTALL INTO THE 3.11 VENV (from backend/):
#   .\.venv-grid-bot-min2\Scripts\python.exe -m pip install -r requirements-pipeline.txt
#
# Then run BOTH uvicorn and the celery worker from that venv. See RUNBOOK_LOCAL.md.
# ─────────────────────────────────────────────────────────────────────────────
